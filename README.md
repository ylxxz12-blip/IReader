# ZReader 本地小说阅读器

类掌阅的 Android 离线小说阅读应用。**不含任何联网功能**，所有数据保存在应用私有目录。

## 功能总览

### 书架
- 通过系统文件选择器（SAF）批量导入本地 TXT / EPUB 文件（自动复制进应用目录，重名同大小自动去重）
- 自动生成渐变色封面，显示阅读进度百分比 / 已读完 / 中英角标
- 书架内搜索；长按书籍查看详情（作者、格式、编码、字数、进度、导入时间）
- 移出书架（可选同时删除导入的文件副本）
- 首次启动自动导入一本中英对照示例书《伊索寓言选》

### 阅读
- **翻页方式**：仿真（卷页折叠）/ 覆盖 / 平移 / 无动画，支持拖拽跟手、惯性滑动（fling）、点击左右翻页、音量键翻页
- **排版设置**：字号、行间距、段间距、衬线字体、5 套阅读背景（纸白/羊皮纸/护眼绿/夜间/纯黑）、亮度调节（可跟随系统）、屏幕常亮
- **目录**：自动识别章节（第X章/节/卷/回、序章、Chapter N、Part N 等），超长章节自动切分
- **进度**：章节内页码、全书百分比、进度条拖动跳转，退出自动记忆
- **书内搜索**：全文关键词定位
- **编码**：自动检测 UTF-8 / UTF-16 / GBK(GB18030)

### 批注
- 阅读时长按文字进入选择模式（中英文自动词组扩展，可拖动手柄调整范围）
- 4 色高亮、笔记（高亮 + 注释文字）、复制、全选段落、删除
- 批注面板：按 高亮/笔记/书签 分类浏览、点击跳转、编辑/删除、一键导出分享
- 书签：在阅读菜单“更多”中添加当前页书签

### 双语阅读
- 导入时自动检测段落级中英交替（中英对照 TXT 常见格式），识别为双语书
- 阅读菜单底部提供 **双语 / 中文 / 英文** 一键切换，进度与批注坐标在全语言模式下保持一致
- 非双语书籍不显示语言切换

## 双语文件格式说明

段落级交替即可，例如：

```
第一章 龟兔赛跑

有一天，兔子在山坡上碰见了乌龟。
One day, a hare happened to meet a tortoise on the hillside.
乌龟很不服气，便提出和兔子赛跑。
The tortoise proposed a race with the hare.
```

判定规则：纯中文段落与纯英文段落交替出现（交替占比 ≥ 50% 且各语言段落 ≥ 4 段），无需任何标记符。

## 技术要点

- Kotlin + Jetpack Compose（书架与菜单）+ 自定义 View（阅读渲染）
- 自研排版引擎：`Paint.breakText` 逐行断行，支持中文首行缩进、段间距、双语段落过滤及 raw↔filtered 偏移映射（批注/进度跨语言模式稳定）
- 翻页动画为 Canvas 实现：仿真模式基于“手指-书角垂直平分线”折叠 + 位图镜像页背
- 持久化：kotlinx-serialization JSON（书架 / 批注）+ SharedPreferences（设置），无网络权限
- EPUB：ZipFile + XmlPullParser 提取 spine 正文，首次打开后缓存为纯文本

## 构建

Android Studio 打开即可构建运行（AGP 9.4 / Kotlin 2.2 / minSdk 31 / targetSdk 37）。
命令行构建：

```
gradlew.bat :app:assembleDebug
```

国内网络已在 `settings.gradle.kts` 配置阿里云镜像（官方仓库兜底）。
